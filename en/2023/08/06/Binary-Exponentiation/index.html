Matrix Exponentiation

Matrix exponentiation is primarily used for linear recurrence counting problems, and for dynamic programming problems whose state transition equations are linear recurrences. Some counting problems allow you to derive a recurrence by manually computing small values of n to spot a pattern. If the recurrence is linear, it can be reformulated as a matrix power problem and accelerated with matrix exponentiation.
