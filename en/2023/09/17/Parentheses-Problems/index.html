Parentheses Problems

2023-09-17
String

Parentheses problems are an interesting problem family, primarily centered around valid parentheses. For example:

  1. Check whether a string is a valid parenthesization
  2. Find the longest valid parentheses substring
  3. Find the longest valid parentheses subsequence
  4. Generate all valid parenthesizations of a given length
  5. …

Before diving into each topic, let’s define what “valid parentheses” means. (), ()()()(), and ((((((()))))))(())() are all valid.
