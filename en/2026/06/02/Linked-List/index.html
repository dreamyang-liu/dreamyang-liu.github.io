Core Linked List Operations

2026-06-02
Data Structures Linked List

Every linked list bug traces back to one sentence: save cur.next before you overwrite it — otherwise you lose the rest of the chain forever. Remember that, add the dummy-node / two-pointer / head-insert-reversal trio, and 80% of linked list problems become template exercises.

Intuition — Save next Before Breaking the Link

The fundamental difference between linked lists and arrays: modify any element in an array and the other elements stay put; overwrite cur.next in a linked list and the original chain is instantly severed — there is no second path back.

So the first line of every template is always nxt = cur.next. The three-step mantra:

  1. Save — nxt = cur.next (the lifeline)
  2. Redirect — cur.next = prev (perform the surgery)
  3. Advance — prev = cur; cur = nxt (move forward)

The animation below walks through all three steps on a 5-node list. Keep your eyes on the three pointers: yellow cur, cyan prev, red nxt. Each time you click “Next Step,” see which arrow flips. The frame where red nxt appears is exactly where “Save” is saving your life.

The Three Core Techniques — Dummy / Two Pointers / Head-Insert Reversal

1. Dummy Head Node — Use It Whenever the Head Can Change

Any problem where the head node might be deleted, swapped, or merged (reversal, merge, delete, group reorder) — open with dummy = ListNode(0, head) and return dummy.next at the end. Cost: one extra node. Benefit: no if head is None checks, no if node == head special cases.

When to skip it: traversal only, value-only changes, no structural modifications (e.g., compute length, find midpoint).

2. Two Pointers — One Trick, Three Problems

Scenario Recipe
Find midpoint slow moves 1 step, fast moves 2; when fast reaches end → slow is at middle
Detect cycle slow 1 step, fast 2 steps; meeting = cycle, never meeting = no cycle
kth from end fast advances k steps first, then both move together; when fast reaches end → slow is at position k from end

Why it works: the speed difference converts “distance” into a quantity you can exploit. Finding midpoint trades “2x speed to the end” for “1x speed to the halfway point”; kth from end trades “k steps of lead” for “k positions of lag.”

3. Head-Insert Reversal — Not Just for Reversing Lists

Each iteration detaches the current node and prepends it to dummy, producing reverse order automatically. Reverse a subrange (LC 92) and reverse in k-groups (LC 25) are both variants of this head-insert pattern.

Mnemonics

One sentence: save next before touching pointers, use dummy whenever the head can change, open two pointers whenever you need to find a position.

Three pairs:

Problem Technique
Head node might change dummy
Need to find a position “midway” two pointers (speed gap or distance gap)
Need to reverse / reverse a segment head-insert to after dummy

For Floyd cycle detection, just remember: a = c (mod L) — distance from start to entry equals distance from meeting point to entry (modulo cycle length). Everything else follows from drawing the diagram. Never write linked list pointer code without drawing a diagram first — that rule is inviolable.
