Difference Array and Prefix Sum

2026-06-02
Data Structures Prefix Sum

Difference array = the inverse of prefix sum. A range update [l, r] += k that would take with a loop becomes two single-point writes diff[l] += k; diff[r+1] -= k in . Finish with one prefix-sum pass to recover the array. Remember that one sentence and you’ll never write a loop for bulk range additions again.

Intuition — The Inverse of Prefix Sum

Think of “prefix sum” and “difference” as a pair of functions:

Operation Formula Analogy
Prefix sum pre[i] = pre[i-1] + a[i] Integration ∫
Difference diff[i] = a[i] - a[i-1] Differentiation d/dx

The two are mutual inverses: difference then prefix sum = original array. This isn’t a coincidence — it’s just the discrete version of the Fundamental Theorem of Calculus.

So an immediate idea emerges: since modifying a range of the original array is expensive ( points to touch), operate on the difference array instead — the cost is just two endpoints. One final prefix-sum pass “materializes” all accumulated modifications at once.

Template — Python

Three easy mistakes:

  1. Allocate diff with n+1 elements to avoid the if r+1 < n guard.
  2. Closed interval [l, r] maps to diff[r+1] -= k; if the problem gives a half-open interval [l, r), use diff[r] -= k instead.
  3. If the original array is not all zeros, compute its difference array first to get the initial diff, then layer the operations on top.

The Duality with Prefix Sum

One is “read-only,” the other is “write-only.” The two are duals — choose based on whether the problem has more queries or more updates. When queries and updates alternate, reach for a segment tree.

Mnemonics

One sentence: update the range’s two endpoints; recover with a prefix sum.

Three contrasting pairs:

Dimension Prefix Sum Difference Array
Solves Range query Range update
Operation Accumulate Take difference
Calculus analogy Integration Differentiation

Decision rules:

  • Read-only (queries only) → prefix sum
  • Write-then-read (updates then one final query, offline) → difference array
  • Interleaved reads and writes (online) → segment tree

Whenever you see “add/subtract a constant across a range” followed by “output or query the result once,” your reflex should be diff[l] += k; diff[r+1] -= k. Can’t go wrong.
